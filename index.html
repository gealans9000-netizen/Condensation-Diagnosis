      계산 방법과 근거

      1. 포화수증기압과 이슬점

      DIN 4108-3 계열의 지수식을 씁니다. 0℃ 초과는 물, 0℃ 이하는 얼음 기준입니다.

      ps = 1.40574×10¹⁰ · exp(−3928.5 / (θ + 231.667)) (θ > 0℃)
      ps = 3.61633×10¹² · exp(−6150.6 / (θ + 273.33)) (θ ≤ 0℃)

      수증기 분압 p = φi · ps(θi), 이슬점은 위 식을 역산합니다. p가 611 Pa 이하면 얼음 기준 식을 써서 서리점을 구합니다.

      2. 내부 표면온도

      fRsi = 1 − Rsi · U, θsi = θe + fRsi · (θi − θe). 외벽은 이 식을 그대로 씁니다. 창호 부위는 표준 조건(Rsi 0.13)의 TDR에서 유효 열관류율 U = TDR / 0.13을 구합니다. 그런 다음 열저항을 합산해 TDR = Rsi / (1/U − 0.13 + Rsi)로 Rsi를 바꿉니다. 유리는 U값이 커서 단순식을 쓰면 커튼이나 가구가 있을 때 표면온도를 지나치게 낮게 계산하기 때문입니다.

      3. 곰팡이 판정

      표면 상대습도가 80%(기본값)에 이르면 곰팡이 위험으로 봅니다(EN ISO 13788, DIN 4108-2). 곰팡이 한계 표면온도 θsi,mold는 ps(θsi,mold) = p / 0.8로 구합니다. 곰팡이가 생기지 않는 최대 실내습도는 결로 한계 습도 × 0.8입니다. DIN 4108-2는 곰팡이 방지를 위해 fRsi ≥ 0.70(TDR ≤ 0.30)을 요구합니다.

      곰팡이 발생까지 걸리는 기간은 Hukka·Viitanen(1999) VTT 모델로 추정합니다. t = exp(−0.68 ln θ − 13.9 ln φ + 66.02)주이며, 소나무 목재 표면 기준입니다. 창틀 실리콘, 먼지, 벽지처럼 유기물이 있는 표면에 대한 대략적인 기준으로 보세요.

      4. 가능성(%)

      실제 표면온도는 시공 품질, 바람, 가구 배치 때문에 계산값 주변에서 흔들립니다. 표면온도에 표준편차 σ의 정규분포를 두고 P(결로) = Φ((θs − θsi) / σ), P(곰팡이) = Φ((θsi,mold − θsi) / σ)로 계산합니다. 결빙은 표면온도가 이슬점과 0℃보다 모두 낮을 확률입니다. 전체 판정은 가장 취약한 부위를 기준으로 합니다.

      5. 판정 단계

      Dew Point Calculator(Image Permanence Institute)의 GOOD / OK / RISK 방식처럼 결과를 단계로 나눕니다. 10% 미만은 안전, 10~40%는 주의, 40~70%는 위험, 70% 이상은 매우 위험입니다.

      6. 이 도구의 한계

      정상 상태(steady-state) 1차원 계산입니다. 요리, 샤워, 빨래 건조처럼 습도가 순간적으로 오르는 상황, 일사, 복사 냉각, 부재 속 습기 축적은 반영하지 않습니다. 벽체 내부의 습기 누적이나 빗물 침투까지 보려면 WUFI Pro 같은 비정상 열·습기 해석이 필요합니다(예: 외단열 시스템 후면에 Driving Rain 1%를 습기 소스로 두는 ASHRAE 160 방식).
